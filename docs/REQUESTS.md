# 수정 요청 양식

홈페이지 수정을 **개발자에게 부탁하거나, AI 도우미에게 붙여 넣을 때** 쓰는 양식입니다. 어느 도구를 쓰든 필요한 정보는 같습니다.
빠진 정보가 있으면 되묻는 일이 생기니, 양식의 항목을 모두 채워 주세요.

## 기본 틀

```
[페이지] 어느 페이지인지 (예: 교육과정, 과정 세부 - 강점세미나 8기, SNS·위치)
[위치]   페이지 안 어디인지 (예: 연간 타임라인 아래 강점세미나 블록)
[현재]   지금 어떻게 보이는지 / 지금 문구
[변경]   어떻게 바꿀지 / 새 문구 (그대로 넣을 수 있게 완성된 문장으로)
[기타]   참고 링크, 사진 파일, 마감 시점
```

## 자주 쓰는 요청 예시

### 새 기수 추가

```
[요청] 강점세미나 9기를 추가해 주세요.
- 목록 제목: 강점세미나 9기 · 주말 일반과정
- 종류: 강점세미나
- 일정: 2026-10-17 ~ 2026-11-07 (매주 토요일 오후 3:00~6:00, 4주)
- 진행: 온라인(Zoom) 참여수업
- 참가비: 정가 30만원 → 10만원 (강점진단비 개인 부담)
- 신청 마감: 2026. 10. 4 / 정원 20명
- 상태: 모집중
- 신청서: (Google Form 주소, 없으면 "공통 신청서")
- 안내문·특징·참여요건: 8기와 동일
```

### 기수 상태 변경

```
[요청] 커플코칭스쿨 15기를 "모집완료"로 바꿔 주세요. (또는 "교육완료")
```

### 문구 수정

```
[페이지] 코칭·상담
[위치]   코칭이란? 첫 문단
[현재]   "코칭(Coaching)은 단지 들어주고 위로하는 시간이거나..."
[변경]   "코칭(Coaching)은 ...(새 문장 전체)"
```

### 연락처 · 링크 변경

```
[요청] 대표 전화번호를 010-0000-0000 으로 바꿔 주세요. (모든 페이지)
[요청] 코칭 요청서 주소를 https://forms.gle/xxxx 로 바꿔 주세요.
```

### 사역 현장 기록 추가

```
[요청] 강의 요청 페이지의 "강의 · 집회 현장" 기록에 한 줄 추가해 주세요.
- 제목과 날짜: "증가교회 청년부 수련회" 2026-08-21
```

### 다음 기수 예고 (일정 미정)

```
[요청] 영성일기 10기를 "추후모집"으로 올려 주세요. 일정은 아직 없고 요일/시간은 토요일 오후 3시~5:30 입니다.
- 신청서: (Google Form 주소, 없으면 9기와 동일)
```

### 코칭 후기 추가

```
[요청] 코칭 후기를 추가해 주세요.
- 글: "..."(전체 문장)
- 이름 · 소속: 홍길동 · 직장인
- 공개 범위: 이름 공개 / 이니셜만
```

### 새 섹션 · 구성 변경 (개발자 작업)

```
[페이지] 교육과정
[요청]   프로그램 블록 위에 "수강생 후기 3개"를 가로로 보여 주는 섹션을 추가
[내용]   후기 3건 (글 · 이름 · 소속)
[참고]   비슷한 예: 코칭·상담 페이지의 후기 카드
[제약]   기존 색·글자 규칙 유지 (CLAUDE.md)
```

## 요청하기 전에 확인할 것

- 문구는 **완성된 문장**으로 주세요. "좀 더 부드럽게"보다 "이 문장으로 바꿔 주세요"가 정확합니다.
- 날짜는 `2026-10-17` 처럼 연-월-일로, 시간은 `오후 3:00~6:00` 처럼 적어 주세요.
- 사진은 원본 그대로 주시면 됩니다. 줄이는 작업은 수정하는 쪽에서 합니다.
- 외부 주소(신청서, 지도 등)는 브라우저에서 한 번 열어 확인한 뒤 주세요.
